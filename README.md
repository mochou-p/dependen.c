# dependen.c
all the ways of using one C code from another  

this does not cover preprocessor strategies around `#include`,  
such as unity builds or precompiled headers  

each directory has the example code and a build script,  
you can try them out like so:  
```sh
# after `cd`-ing into one of the directories
$ make && ./a.out
```
